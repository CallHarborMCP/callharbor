# Roadmap beyond v1 (future possibilities, not blockers or deliverables for v1)

All items are ideas for follow-up versions; no v1 code should pretend to implement them.

- Live mid-call instructions and supervision from web GUI, human takeover and hand-off.
- Inbound calls and AI receptionists; IVR/queue integration and voicemail handling.
- Multiple telephony operators beyond Telnyx: SIP trunk adapters, Twilio, etc.
- Batch/outbound campaigns, scheduling, workflows and multiple agents.
- Advanced local/remote multimodal models, bring-your-own inference pipelines, quality analytics, sentiment/QA, CRM/calendar/calendar bookings.
- Organization/team roles beyond two-role v1, enterprise policy/retention and billing integrations.
- Optional recording consent/legal announcement policies per jurisdiction (not v1; must never be mandatory or assumed).

Architect v1 using clean internal interfaces for future alternatives, but implement only required v1 providers/functions.
